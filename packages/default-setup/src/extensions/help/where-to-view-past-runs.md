# Where can I view past runs?

Every flow run is kept for 30 days in the run history, which you can browse from the Database Explorer surface.

1. Open the **Database Explorer** surface.
2. Click the **⋮** (three dots) menu in the top-left breadcrumbs row.
3. Select **View Run History**.

You'll see the flows that ran, newest first (e.g. Root Flow, start command listener, Handle flow, run onboarding), each with when it started. Click a run to expand its events and inspect what ran.
