# 👋 Welcome to AgentBuddy

AgentBuddy is a local-first AI coding workspace that turns raw CLI interactions into a structured, visual, and persistent development experience. Instead of working in ephemeral terminal sessions, you work in threads—organized, resumable conversations with rich context and artifacts.

---

## ⚡ What You Can Do

- Chat with Claude Code in real-time with streaming responses  
- Manage work in threads with statuses, tags, and history  
- Approve or deny tool actions (edit, write, bash) interactively  
- View file changes as inline diffs and structured artifacts  
- Fork, rewind, and resume coding sessions  
- Build automation using a visual flow engine  
- Edit code, run terminal commands, and manage files in one place  
- Store notes, documents, and reusable knowledge  

---

## 🧭 How It Works

AgentBuddy is built around a few key areas:

- **Toolbar (left):** Switch between plugins like Threads, Notes, Code, and Flows  
- **Canvas (top):** Displays the active view (thread dashboard, editor, flows, etc.)  
- **Chat (bottom):** Where you interact with Claude Code  
- **Inspection Panel (right):** Contextual details and debugging tools  

Most interactions happen through the **chat**, but the system is powered by flows and actions behind the scenes.

---

## 🚀 Getting Started

1. Open the **Threads** plugin (default view)  
2. Create or select a thread  
3. Type your request in the chat  
4. If prompted, select a project directory  
5. Watch responses stream in real-time  
6. Approve any tool actions when prompted  
7. Review diffs and artifacts generated from each turn  

You now have a persistent, resumable coding session.

---

## 🧠 Key Concepts

- **Thread** — A conversation + workspace for a task  
- **Message** — A single interaction in a thread  
- **Artifact** — Outputs like diffs, plans, or stats  
- **Block** — Interactive UI elements (approve, input, select)  
- **Flow** — Automation logic that reacts to events  
- **Action** — A reusable function executed by flows  
- **Session** — The underlying Claude Code CLI state  

---

## 💡 Tips

- Use `cc-fork` to branch a conversation without losing context  
- Use `cc-compact` to reduce context size in long threads  
- Enable additional plugins in **Settings → Plugins**  
- Use Kanban view to manage threads visually  
- Inspect flow execution using the Brain debugger  

---

Start simple: open a thread, ask for help, and follow the flow. The system builds around you as you go.
