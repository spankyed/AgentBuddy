## PROJECT STRUCTURE FACTS

1. The project is located at: /Users/spankyed/Develop/Projects/AgentBuddy

3. The project has these packages:

   - packages/preload (Electron preload scripts)
   - packages/renderer (Vue.js frontend)

================================================================================

## API SERVER REQUIREMENTS

1. **Location at Runtime**:
   - The API server code is in packages/api/dist/server.js
   - It must be accessible from the packaged Electron app

2. **How It's Launched**:
   - The main process spawns it as a child process using Node.js
   - Code: spawn('node', ['dist/server.js'], { cwd: apiPath })
   - Located in: packages/main/src/modules/ApiServer.ts

3. **Dependencies Required**:
   - The API server imports these packages at runtime:
     * zod
     * ws (WebSocket)
     * @ai-sdk/anthropic
     * @ai-sdk/openai
     * ai
     * better-sqlite3 (native module)
     * node-pty (native module)
     * usearch (native module)
     * fastembed
     * onnxruntime-node (native module)
     * And approximately 30+ other dependencies

4. **Native Modules (imported by API server)**:
   - better-sqlite3 - SQLite database binding
   - node-pty - Terminal emulation
   - usearch - Vector search
   - onnxruntime-node - Machine learning runtime
   - These must be compiled for the correct Electron version

5. **Environment Variables**:
   - API_PORT: '3001'
   - DATABASE_PATH: app.getPath('userData') + '/database.db'
   - USER_DATA_PATH: app.getPath('userData')
   - NODE_ENV: 'production' or 'development'

================================================================================

## MAIN PROCESS REQUIREMENTS

1. **Entry Point Chain**:
   - packages/entry-point.mjs imports from packages/main/dist/index.js
   - This import currently uses: import {initApp} from './main/dist/index.js'

2. **Renderer Path Resolution**:
   - Must resolve to: packages/renderer/dist/index.html
   - Currently uses: fileURLToPath(new URL('./renderer/dist/index.html', import.meta.url))

3. **Preload Path Resolution**:
   - Must resolve to: packages/preload/dist/exposed.mjs
   - Currently uses: fileURLToPath(new URL('./preload/dist/exposed.mjs', import.meta.url))

4. **API Server Management**:
   - Must start API server before creating window
   - Waits for "WebSocket Server listening" message to confirm startup
   - Must handle API server crashes and restart (max 3 attempts)

## SOME POTENTIAL RUNTIME ERRORS

1. **Module Resolution Errors**:
   - "Cannot find package 'zod' imported from [api path]/dist/server.js"
   - "Cannot find package '@ai-sdk/provider-utils'"
   - "Cannot find module '../build/Debug/pty.node'"

2. **Path Resolution Errors**:
   - "Cannot find package '@app/main' imported from entry-point.mjs"
   - API path not found in production

3. **Native Module Errors**:
   - "was compiled against a different Node.js version using NODE_MODULE_VERSION 136"
   - Native modules need electron-rebuild for correct version
